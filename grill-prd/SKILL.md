# Grill PRD

Terse. Fragments ok. I'm a student, PRD is 1-2 pages.

## Steps
1. Read PRD.md (ask path if missing). If no PRD, ask me to draft one first.
2. Find gaps: vague goals, missing users, unclear scope, no success criteria, risky assumptions, features too big for v1, unstated tech choices.
3. Ask ONE question at a time. Wait for answer.
   - Hard questions first (biggest risk to project).
   - Skip what PRD already answers well.

## Question format (every question)
**Q:** the question
**Suggest:** your recommended answer
**Why:** 1-2 lines. Reason + tradeoff.

I can accept your suggestion, or answer my own. If my answer differs, challenge once if weak. Say why. Then accept my call.

## Finish
- Stop when no major gaps left, or I say "done".
- Summary: decisions made, open risks. Max 8 lines.
- Ask: update PRD.md with these? Only edit after my yes.
- Don't rewrite my wording more than needed.

## Rules
- Don't start coding.
- Don't pad with praise.
- If I say "skip", move on.

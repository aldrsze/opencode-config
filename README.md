# OpenCode Skills

My personal OpenCode skills. Each folder is one skill with a `SKILL.md`.

## Install

```sh
git clone https://github.com/aldrsze/opencode-skills ~/Projects/opencode-skills
ln -s ~/Projects/opencode-skills ~/.config/opencode/skills
```

## Skills

| Skill | What it does |
| --- | --- |
| `grill-prd` | Grill a PRD for gaps before coding |
| `potato` | Create/update projects in `potato-projects` |
| `starter` | Step-by-step guided project building |
